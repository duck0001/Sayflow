SayFlow 1.4 — iPhoneの音声を改善（動的な音声）

【変更】
・今までの272本の機械音声ファイルをすべて削除し、HTMLを約3.3MB→約130KBに軽量化。
・iPhone「ショートカット」から任意の英文を読み上げられるモードを搭載（音声ファイル追加・APIキー不要）。
・Safari内蔵の音声合成も維持し、英語の声を手動選択できる診断を追加。
・iPhoneの「選択項目の読み上げ」を利用する方法も追加。
・会議英語、検索、練習、お気に入り、バブルは維持。

【ショートカットの初回設定】
1. iPhoneの「ショートカット」で新規作成し、名前を SayFlow Speak にする。
2. アクション「テキストを読み上げ」を追加。
3. 読み上げ対象を「ショートカットの入力」にする。
4. 英語（アメリカ）の好きな声を選んで保存。
5. SayFlowの設定で「ショートカットの音声テスト」をタップ。

【GitHub Pages更新】
・リポジトリの最上位に index.html と sw.js を上書きコミットしてください。
・manifest.webmanifestとiconsは前のものを継続利用できます。
・GitHub Pagesの自動公開が終わったらアプリを一度閉じ、Safariから再度開いてください。

【制限】
・ショートカット方式はiPhoneのショートカットアプリへ切り替わります。声質はショートカット内の選択次第です。
・Safariの音声合成はApple側の実装に依存し、無音の問題を完全に解消したと保証するものではありません。
・機密情報や個人情報はアプリ内の文例に登録しないでください。
